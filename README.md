# Тестовое задание: автотест установки TCP-соединения

## Что проверяет
Автотест проверяет, что клиент устанавливает TCP-соединение
с сервисом-симулятором на `127.0.0.1:2001`.

## Стек
- Python 3.10+
- pytest
- стандартная библиотека (`socket`, `subprocess`)

## Установка
```bash
pip install -r requirements.txt
```

## Запуск
```bash
pytest test_connection.py -v
```

## Структура
- `test_connection.py` — сам тест
- `conftest.py` — фикстура, поднимающая сервис-симулятор
- `signal_service_simulator.py` — минимальная заглушка сервиса

## Оговорки
- Тест проверяет только факт установки TCP-соединения.
- Симулятор принимает соединение и сразу его закрывает —
  проверки 10 сигналов в этом тесте нет.
